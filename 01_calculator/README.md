# 🧮 Simple Calculator

A beginner Python program that performs basic arithmetic operations based on user input.

## 📌 Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles division by zero
* Handles invalid operators

## 🧠 Concepts Used

* Variables
* User input
* Data type conversion
* Conditional statements
* Arithmetic operators
* Basic error handling


## 💻 Example

text
Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5

Result: 50.0
