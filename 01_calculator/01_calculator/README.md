# 🧮 Simple Calculator

A beginner Python program that performs basic arithmetic operations based on user input.

## 📌 Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Handles invalid operators

## 🧠 Concepts Used

- Variables
- User input
- Data type conversion
- Conditional statements
- Arithmetic operators
- Basic error handling

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python calculator.py
