# 🎯 Number Guessing Game

A beginner Python game where the player tries to guess a randomly generated number between 1 and 100.

## 📌 Features

- Generates a random number between 1 and 100
- Accepts guesses from the user
- Gives hints when the guess is too high or too low
- Counts the number of attempts
- Ends when the correct number is guessed

## 🧠 Concepts Used

- Variables
- User input
- `int()` type conversion
- `if`, `elif`, and `else`
- `while` loops
- `break`
- `random` module
- `random.randint()`
- Counters
- f-strings
