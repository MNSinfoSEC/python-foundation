# 🔐 Password Generator

A beginner Python program that generates a random password using letters, numbers, and special characters.

## 📌 Features

- Allows the user to choose the password length
- Generates random characters
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters

## 🧠 Concepts Used

- Variables
- User input
-  int()  type conversion
-  for  loops
-  random.choice()
- Python modules
-  Strings
-  string.ascii_letters
-  string.digit
